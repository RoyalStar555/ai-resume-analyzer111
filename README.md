# 🎯 ATS Lens: AI-Powered Resume Analyzer

![ATS Lens Banner](https://via.placeholder.com/1000x300?text=ATS+Lens+-+Beat+the+Bots)

**Live Demo:** [ATS Lens on Lovable](https://ai-resume-analyzer111.lovable.app/)

ATS Lens is a full-stack, AI-integrated application designed to help job seekers crack Applicant Tracking Systems (ATS). By grading your resume against a target job description like a ruthless senior tech recruiter, it provides actionable insights, visual data, and AI-powered bullet rewrites to help you land the interview.

## ✨ Features

* **Strict ATS Scoring:** Parses PDF resumes directly in the browser and calculates a rigorous mathematical keyword match percentage.
* **Skill Gap Analysis:** Instantly categorizes your tech stack into "Detected," "Required," and "Missing" badges.
* **Generative AI Rewrites:** Automatically transforms weak, passive bullet points into high-impact, quantifiable achievements.
* **Dynamic Visual Dashboards:** Beautiful, interactive charts (using Recharts) breaking down strong points, weak points, and actionable suggestions.
* **Client-Side Parsing:** Uses `pdfjs-dist` to securely extract text from PDFs directly in the browser without uploading your sensitive documents to a server.
* **Secure Authentication & History:** Powered by Supabase to securely save user accounts and past resume analyses using Row Level Security (RLS).
* **Exportable Reports:** Generates clean, professional PDF reports of the personalized analysis.

## 🛠️ Tech Stack

**Frontend:**
* React.js
* Vite
* TanStack Start (Routing)
* Recharts (Data Visualization)
* Tailwind CSS / Custom CSS (Glassmorphism UI)

**Backend & Database:**
* Supabase (PostgreSQL Database)
* Supabase Auth (User Authentication)
* Row Level Security (RLS)

**AI & Utilities:**
* Generative AI Integration (via Lovable AI Gateway)
* `pdfjs-dist` (PDF Text Extraction)
